# Amit Kumar portfolio (React + Vite + Three.js)

## Run on your computer
    npm install
    npm run dev

## Build
    npm run build      # output goes to dist/

## Host on GitHub Pages
1. Upload all these files to a GitHub repository (branch main).
2. Settings, Pages, Source: GitHub Actions.
3. Every push to main builds and publishes the site.

## Edit content
- src/data.js: education, skills, projects, links
- src/App.jsx: page sections
- src/index.css: styles
- src/three.js: 3D orb, office and walking employees
- src/assets: your photos
- public/document/amit.pdf: your CV
